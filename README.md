# Cybersecurity-journey


Este repositorio tiene como fin ser mi libreta de notas, aqui voy a ir añadiendo todo lo que vaya aprendiendo sobre ciberseguridad, programación, herramientas, etc.
Voy iniciar desde un nivel básico pero no desde cero.

objetivos:

* Documentar mi progreso de forma ordenada
* Que pueda consultarlo como si fuera una guia
* Almacenar recursos (links, notas, etc)


---


Guia de estudio (tentativa):

## 1. Sistemas Operativos y terminal

* Windows: archivos, procesos y usuarios
* CMD: ipconfig, ping, tracert, nslookup, netsat
* PowerShell: comandos, tuberías, filtros y scripts básicos
* Linux: terminal, directorios, archivos y permisos
* Linux: usuarios, procesos, servicios y paquetes
* Logs de Windows y Linux
* Máquinas virtuales y entornos de laboratorio

## 2. Redes y protocolos

* Modelo TCP/IP y modelo OSI
* IPv4, direcciones privadas/públicas y loopback
* Máscaras, CIDR y subnetting
* Gateway, routing y tablas de rutas
* Switches, VLAN y segmentación
* TCP, UDP, puertos y sockets
* DNS, DHCP, ARP, ICMP y NAT
* HTTP, HTTPS, TLS y certificados
* SSH, FTP/SFTP, SMTP y otros protocolos comunes
* Wi-fi, VPN y conceptos de proxy
* Wireshark: capturar y analizar tráfico
* Cisco Packet Tracer: construir y diagnosticar redes
* Firewalls: reglas de entrada/salida y troubleshooting

## Programación y herramientas de desarrollo

* Python: variables, tipos, condicionales y ciclos
* Python: funciones, colecciones, módulos y excepciones
* Python: archivos, JSON, expresiones regulares y logs
* Python: solicitudes HTTP y uso de APIs
* Depuración, pruebas unitarias y manejo de errores
* Git: commits, ramas, merge y resolución de conflictos
* GitHub: repositorios, README, issues y pull requests
* SQL: SELECT, WHERE, JOIN, GROUP BY y agregaciones
* JSON, CSV, YAML y formatos habituales
* Bash y REST APIs: solicitudes, respuestas y códigos de estado
* Fundamentos de JavaScript y seguridad de aplicaciones
* Fundamentos de C: memoria y sistemas (etapa posterior)

## Fundamentos de ciberseguridad

* Confidencialidad, integridad y disponibilidad
* Autenticación, autorización y MFA
* mínimo privilegio y control de acceso
* Hashing, cifrado simétrico y asimétrico
* Gestión de vulnerabilidades, parches y configuración segura
* Malware, phishing, ransomware y otras amenazas
* Indicadores de compromiso (IOC)
* Gestión de riesgos y severidad de hallazgos
* Falsos positivos y falsos negativos
* Respuesta a incidentes y documentación
* Seguridad de endpoints y servidores
* Ética, autorización y límites de las pruebas de seguridad
